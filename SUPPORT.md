# Support

Start with [Maps](docs/maps.md), [Rendering](docs/rendering.md), or
[Resolution](docs/resolution.md), depending on the failing step.
For help, open an [issue](https://github.com/altophp/importmap/issues) with PHP and
package versions, a minimal map, requested specifier and referencing URL, and
expected versus actual output. Include the browser request URL for loading
problems. Remove private URLs, tokens, and credentials before sharing.
